## Root cause

Pet terms existed only in the fallback classifier. Any allowed Gemini category was accepted before fallback, even when the transaction text explicitly named the pet brand or animal food.

## Approved fix

Treat brand prefix 'булка дол' and explicit pet-purpose terms as deterministic Pets categories before invoking Gemini.

**Why this is causal:** The explicit category branch has priority over model categorization, so recognized pet transactions can no longer be overridden by an allowed but semantically wrong provider response.
