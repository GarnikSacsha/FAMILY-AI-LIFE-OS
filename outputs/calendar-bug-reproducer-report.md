## Root cause

The calendar date branch had no numeric day-month parser and returned None for 11.08.

## Approved fix

Added numeric day-month parsing with optional year and support for colon, dot, and hyphen time separators; preserved relative-date parsing and cleaned date/time fragments from event titles.

**Why this is causal:** The new branch constructs the requested local datetime before the Google Calendar tool is called.
