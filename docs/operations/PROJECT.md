## Почему нельзя просто оставить самую новую папку

Сравнение фактических исходников с локальной `main` показало:

- `expense-release`: четыре отличающихся runtime-файла, включая валидацию
  расходов и безопасность текста Sheets.
- `oura-strict-release`: пять дополнительных runtime-файлов и 16 отличающихся
  файлов. Есть функции здоровья, которых нет в локальной `main`.
- основной каталог: шесть дополнительных runtime-файлов, 14 отличающихся и
  отсутствующая относительно `main` миграция `015_health_data_foundation.py`.
- вложенные worktree содержат собственные незавершённые модели и миграции.

Числа относятся к `app/`, Python/Mako-файлам Alembic и пяти корневым файлам
сборки/запуска; переводы строк нормализованы. Это инвентаризация различий,
не заключение об исправности или ненужности файлов.

## Очередь объединения

| Порядок | Работа | Критерий завершения |
|---|---|---|
| 1 | Восстановить состав действующей сборки по runtime-файлам или проверенному пакету релиза | Известны база, полный состав файлов и контрольные суммы; метаданных Railway недостаточно. |
| 2 | Создать отдельную ветку интеграции от подтверждённой базы | Исходные worktree и все локальные изменения сохранены; новая база воспроизводится. |
| 3 | Сопоставить финансовые исправления `5a3f9bc` с действующей Oura-версией | Проверены даты/категории, валидация, безопасность текста, повторная синхронизация. |
| 4 | Переносить публичные страницы, OAuth и планировщик отдельными небольшими изменениями | Для каждого переноса есть выбранный diff и относящиеся к нему проверки. Bitrix и demo не включаются без решения о составе продукта. |
| 5 | Отдельно решить судьбу health-platform и context-repro | Устранены пересечения миграций; эксперимент не выдаётся за рабочую функцию. |
| 6 | Проверить единую версию и записать процедуру выпуска | Пройдены проверки из RELEASE.md; код готов к ревью. Выкладка — отдельное явное действие. |
| 7 | Архивировать подтверждённо сохранённые снимки и убрать ненужные worktree | У каждого источника есть место сохранения уникальных изменений; точный перечень переносов/удалений согласован. |

Эта очередь составлена на первом этапе уборки. Текущий результат объединения,
сохранённые источники и оставшиеся проверки перечислены в
[CONSOLIDATION.md](CONSOLIDATION.md). Старые папки сохраняются.

## Как обновить карту

Из основного каталога, в PowerShell:

```powershell
rtk git status --short
rtk git -c core.quotePath=false worktree list
rtk proxy ..\FAMILY-AI-LIFE-OS\.venv\Scripts\python.exe -B -X utf8 scripts/workspace_inventory.py
```

Скрипт выводит JSON и ничего не записывает. Он читает только Git-метаданные и
разрешённые исходники/файлы сборки. Содержимое `.env`, ключей, баз, `outputs/`
и диагностики не читается. Полученный список различий не является списком
файлов на удаление. Предупреждения доступа к untracked-каталогам требуют
отдельного разбора.

Снимок этой сверки: [workspace-inventory.json](workspace-inventory.json).
